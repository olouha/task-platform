# 山东烟台钢筋价格抓取规则

## 核心要求

1. **每次抓取必须先存储Excel并累积sheet页**
2. **必须带上抓取的截图**

## 抓取频率

每天抓取 **2次**：
- **上午 (AM)**: 10:00 发布
- **下午 (PM)**: 16:00 左右发布

## Sheet命名规则

格式：`YYYY-MM-DD_{AM/PM}_HHMMSS`

- `YYYY-MM-DD`: 日期
- `AM/PM`: 0-12点为AM，12-24点为PM
- `HHMMSS`: 抓取时间（精确到秒）

示例：
- `2026-05-13_AM_210603` - 5月13日上午21:06:03抓取
- `2026-05-13_PM_210611` - 5月13日下午21:06:11抓取
- `2026-05-16_PM_211954` - 5月16日下午21:19:54抓取

## Excel存储规则

1. **文件路径**: `services/data/山东烟台钢筋价格.xlsx`
2. **累积sheet页**: 每次抓取创建新sheet，**不删除旧数据**
3. **截图嵌入**: 每个sheet末尾嵌入当日截图
4. **截图文件**: `screenshot_{YYYY-MM-DD}_{AM/PM}.png`

## 截图要求

- 格式: PNG
- 尺寸: 900×500 像素
- 位置: 数据下方，标注"当日截图"
- 保存位置: `services/data/`

## AM/PM颜色区分

- **AM (上午)**: 表头蓝色 (`#4472C4`)
- **PM (下午)**: 表头红色 (`#FF6B6B`) - 标注为"晚"

## 抓取逻辑

1. **登录**: 使用 `services/data/mysteel_config.json` 中的凭据
2. **获取URL**: 从我的钢铁网首页或烟台市场页面获取当日URL
3. **抓取AM**: 访问上午URL，提取价格，保存为 `YYYY-MM-DD_AM_HHMMSS`
4. **抓取PM**: 访问下午URL，提取价格，保存为 `YYYY-MM-DD_PM_HHMMSS`
5. **去重**: 按 (品名, 规格, 品牌, 价格) 去重

## 品名范围

只抓取以下品名：
- 高线
- 螺纹钢
- 盘螺
- 圆钢

## 数据字段

| 列 | 说明 |
|----|------|
| 日期 | YYYY-MM-DD |
| 时间 | 抓取时间 HH:MM:SS |
| 品名 | 高线/螺纹钢/盘螺/圆钢 |
| 规格 | 如 Φ6, Φ8, Φ10 |
| 材质 | 如 HPB300, HRB400E |
| 品牌/钢厂 | 钢厂名称 |
| 单价(元/吨) | 数字 |
| 涨跌 | 空白 |
| 备注 | 空白 |
| 钢号 | 空白 |
| 地区 | 山东烟台 |

## 注意事项

1. 每天下午的价格通常比上午低（近期趋势下降10元/吨）
2. 如某时段未发布，跳过该时段
3. URL中的hash会变化，不能硬编码
4. Cookie有效期约1天，建议每次重新登录
