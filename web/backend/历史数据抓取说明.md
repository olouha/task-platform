# 烟台钢筋价格历史数据抓取工具 v2.0

## 功能特性

### 1. 人机模拟
- **随机鼠标移动**: 模拟真实用户浏览时的鼠标移动
- **随机滚动**: 随机上下滚动页面
- **随机延迟**: 每次操作之间随机等待2-5秒
- **模拟阅读行为**: 综合模拟人类浏览页面的行为

### 2. 早晚价格抓取
- **AM时段**: 上午价格（约10点发布）
- **PM时段**: 下午价格（约16点发布）
- 每天抓取两个时段，确保数据完整性

### 3. 完整性验证
- 每天确保不少于11条价格数据
- 自动验证AM和PM时段数据量
- 记录数据不足的日期供后续补充

### 4. 手动登录支持
- 支持手动登录模式
- 自动保存登录Cookie
- Cookie有效期可达数周

### 5. 账号管理
- 支持更新登录凭据
- 凭据加密存储
- 自动登录失败时回退到手动登录

### 6. 历史数据覆盖
- 支持从2024年到2026年6月10日
- 自动跳过已有数据的日期
- 支持断点续抓

## 快速开始

### 方法1: 使用批处理工具（推荐）

双击运行 `web\backend\历史数据抓取.bat`，然后选择对应功能：

```
1. 首次使用 - 手动登录并保存Cookie
2. 更新登录凭据
3. 开始抓取 (2024-01-01 至 2026-06-10)
4. 自定义日期抓取
5. 检查数据完整性
```

### 方法2: 命令行直接运行

```bash
# 进入后端目录
cd web/backend

# 首次使用 - 登录并保存Cookie
python services/fetch_history_enhanced.py --login-only

# 开始抓取历史数据
python services/fetch_history_enhanced.py --start 2024-01-01 --end 2026-06-10 --interval 5

# 更新凭据
python services/fetch_history_enhanced.py --update-credentials

# 无头模式抓取
python services/fetch_history_enhanced.py --start 2024-01-01 --end 2026-06-10 --headless
```

## 使用流程

### 第一步: 首次登录

1. 运行批处理工具，选择 `1. 首次使用 - 手动登录并保存Cookie`
2. 浏览器会自动打开登录页面
3. 手动输入账号密码完成登录
4. 登录成功后Cookie自动保存，可使用数周

### 第二步: 开始抓取

1. 运行批处理工具，选择 `3. 开始抓取`
2. 确认日期范围和间隔时间
3. 程序自动开始抓取
4. 抓取过程中可以看到实时进度

### 第三步: 检查完整性

1. 抓取完成后，选择 `5. 检查数据完整性`
2. 查看是否有数据不足的日期
3. 对不足日期进行补充抓取

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--start` / `-s` | 开始日期 (YYYY-MM-DD) | 2024-01-01 |
| `--end` / `-e` | 结束日期 (YYYY-MM-DD) | 2026-06-10 |
| `--interval` / `-i` | 抓取间隔秒数 | 5 |
| `--headless` | 无头模式（不显示浏览器） | False |
| `--login-only` | 仅登录并保存Cookie | - |
| `--update-credentials` | 更新登录凭据 | - |

## 数据存储

### 数据库 (SQLite)
- 路径: `services/data/yantai_rebar.db`
- 表结构: `rebar_prices`
- 字段: date, period, material_name, spec, brand, price, region, screenshot_path

### Excel文件
- 路径: `services/data/烟台钢筋价格_完整历史_2024_2026.xlsx`
- 每个日期创建两个Sheet: `{日期}_AM_时间` 和 `{日期}_PM_时间`
- 包含价格数据和截图

### 日志文件
- 路径: `services/data/fetch_history_enhanced.log`
- 记录抓取过程和错误信息

## 抓取策略

### 日期过滤
- 只抓取工作日（周一到周五）
- 跳过周末

### URL格式
```
AM时段: https://jiancai.mysteel.com/m/YYMMDD10/25B3355C6617BD3C.html
PM时段: https://jiancai.mysteel.com/m/YYMMDD16/25B3355C6617BD3C.html
```

### 人机模拟参数
- 鼠标移动: 1-3次，每次50-200ms
- 滚动: 1-2次，每次-200到200像素
- 延迟: 2-5秒随机
- 抓取间隔: 可配置（默认5秒）

## 常见问题

### Q: 登录失败怎么办？
A: 使用 `--login-only` 模式手动登录，或者使用 `--update-credentials` 更新账号密码

### Q: 抓取过程中断怎么办？
A: 程序支持断点续抓，重新运行会跳过已有数据的日期

### Q: 某些日期数据不足11条？
A: 使用完整性检查功能查看不足日期，然后自定义日期范围补充抓取

### Q: Cookie过期怎么办？
A: 重新运行 `--login-only` 模式登录即可

### Q: 如何加快抓取速度？
A: 减少间隔时间，如 `--interval 3`，但注意可能被网站限制
