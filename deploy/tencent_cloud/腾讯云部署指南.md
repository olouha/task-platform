## 购买服务器

### 推荐配置

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 实例规格 | 2核4GB 或以上 | 保证运行流畅 |
| 操作系统 | Windows Server 2022 | 最新稳定版 |
| 系统盘 | 50GB SSD | 系统盘 |
| 数据盘 | 100GB+ | 存放日志和数据 |
| 带宽 | 3Mbps 或以上 | 按需选择 |

### 购买步骤

1. 登录腾讯云控制台：https://console.cloud.tencent.com/
2. 选择「云服务器」→「新建实例」
3. 按照推荐配置选择
4. 设置密码（务必记住！）
5. 确认购买

## 服务器初始化

### 步骤 1: 远程连接服务器

方式一：使用腾讯云控制台
1. 进入云服务器控制台
2. 找到你的服务器，点击「登录」

方式二：使用 Windows 远程桌面
1. 按 `Win + R`，输入 `mstsc`
2. 输入服务器公网 IP
3. 输入用户名（默认 `Administrator`）和密码

### 步骤 2: 安装 Python

1. 下载 Python：https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
2. 运行安装程序，**务必勾选 "Add Python to PATH"**
3. 验证安装：打开 PowerShell 运行 `python --version`

### 步骤 3: 安装 Nginx（推荐）

1. 下载 nginx：http://nginx.org/en/download.html
2. 下载 `nginx/Windows-1.24.0` 版本
3. 解压到 `C:\nginx`
4. 验证安装：
```powershell
C:\nginx\nginx.exe -v
```

### 步骤 4: 安装 Git（可选，用于更新代码）

1. 下载 Git：https://git-scm.com/download/win
2. 运行安装程序，使用默认配置

## 安全组配置

### 开放端口

在腾讯云控制台配置安全组，开放以下端口：

| 端口 | 协议 | 说明 |
|------|------|------|
| 80 | TCP | HTTP 访问 |
| 443 | TCP | HTTPS 访问（如果需要） |
| 3389 | TCP | 远程桌面（可限制来源 IP） |

### 配置步骤

1. 进入云服务器控制台
2. 点击你的实例
3. 选择「安全组」→「配置规则」
4. 添加入站规则，开放上述端口

## 部署应用

### 方式一：手动上传（简单）

1. 在本地打包项目：
```powershell
# 在项目目录下
tar -czf task-platform.tar.gz web deploy
```

2. 通过远程桌面的复制粘贴功能，将文件复制到服务器 `C:\taskplatform\`

3. 在服务器上解压：
```powershell
cd C:\
tar -xzf task-platform.tar.gz
```

### 方式二：使用 Git（推荐）

在服务器上执行：
```powershell
cd C:\
git clone https://gitee.com/olouha/task-platform.git taskplatform
```

### 配置环境变量

1. 创建环境配置文件：
```powershell
cd C:\taskplatform\web\backend
copy .env.example .env
notepad .env
```

2. 编辑 `.env` 文件，填写实际配置：
```env
# 数据库配置
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key

# AI服务配置
AI_API_URL=https://api.openai.com/v1
AI_API_KEY=sk-your-key

# 应用配置
LOG_LEVEL=INFO
```

### 安装 Python 依赖

```powershell
cd C:\taskplatform\web\backend
pip install -r requirements.txt
```

### 配置 Nginx

1. 复制 nginx 配置：
```powershell
copy C:\taskplatform\deploy\tencent_cloud\nginx-windows.conf C:\nginx\conf\nginx.conf
```

2. 修改配置中的服务器名称（如果需要）：
```powershell
notepad C:\nginx\conf\nginx.conf
```

找到 `server_name localhost;`，改为你的域名或 IP。

3. 测试配置：
```powershell
C:\nginx\nginx.exe -t
```

## 启动服务

### 一键启动

```powershell
cd C:\taskplatform\deploy\tencent_cloud
.\start.ps1
```

### 验证服务

1. 在服务器上测试：
```powershell
curl http://localhost:8000/health
```

2. 在本地浏览器访问：
```
http://你的服务器IP:8000/docs
```

### 设置开机自启（可选）

创建任务计划：

```powershell
# 创建启动脚本
"C:\taskplatform\deploy\tencent_cloud\启动.bat" | Out-File -FilePath "C:\taskplatform\autostart.bat"

# 使用任务计划程序设置开机自启
# 或者：将启动脚本的快捷方式放到启动文件夹
shell:startup
```

## 域名配置（可选）

### 步骤 1: 购买域名

在腾讯云或其他域名服务商购买域名

### 步骤 2: 解析域名

在腾讯云 DNS 控制台添加解析：

| 记录类型 | 主机记录 | 记录值 |
|----------|----------|--------|
| A | @ | 你的服务器公网 IP |
| A | www | 你的服务器公网 IP |

### 步骤 3: 等待解析生效

通常 10-30 分钟生效

### 步骤 4: 修改 nginx 配置

```powershell
notepad C:\nginx\conf\nginx.conf
```

修改 `server_name` 为你的域名：
```nginx
server_name your-domain.com www.your-domain.com;
```

重启 nginx：
```powershell
C:\nginx\nginx.exe -s reload
```

## 故障排除

### 问题 1: 无法访问服务器

1. 检查安全组是否开放 80/8000 端口
2. 检查服务器防火墙设置
3. 确认服务是否启动

### 问题 2: 服务启动失败

1. 查看日志：`.\view-logs.ps1`
2. 检查 Python 依赖是否安装完整
3. 确认 `.env` 文件配置正确

### 问题 3: 端口被占用

```powershell
# 查找占用进程
netstat -ano | findstr :8000

# 终止进程
taskkill /PID <进程ID> /F
```
