## 如果无法运行脚本，手动操作：

### 1. 修改配置文件
在服务器上打开文件：`C:\taskplatform\config\cloud.json`

替换为以下内容：
```json
{
  "mode": "sqlite",
  "supabase_url": "",
  "supabase_key": "",
  "version": "1.0.0"
}
```

### 2. 重启服务
在服务器上打开 PowerShell，运行：
```powershell
cd C:\taskplatform
taskkill /F /IM python.exe
python -m uvicorn web.backend.main:app --host 0.0.0.0 --port 8000
```

### 3. 验证
访问：http://140.143.125.234/
