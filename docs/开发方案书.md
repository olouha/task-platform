# TaskPlatform 工程调差计算系统
## 开发方案书

---

## 一、项目概述

### 1.1 项目背景

建筑工程中，材料价格波动直接影响工程成本。需要一个系统实现：
- 自动化抓取市场价格（我的钢铁网、有色金属网、信息价）
- 历史价格永久存储，随时查阅
- 自动计算材料调差金额
- 多人协作，实时同步

### 1.2 目标用户

- 项目经理：查看调差报表
- 造价员：录入数据、查看价格趋势
- 领导：查看整体成本情况

### 1.3 核心功能

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 价格监控 | 自动抓取多网站价格 | P0 |
| 分时段查阅 | 按日/周/月/年查看历史价格 | P0 |
| 调差计算 | 根据基准价与现价自动计算调差 | P0 |
| 指标库 | 进度/质量/成本/安全指标 | P1 |
| 多人协作 | 实时同步数据 | P1 |
| 报表导出 | Excel/PDF 调差报告 | P2 |

## 五、开发步骤详解

### 步骤1：环境准备（2小时）

```bash
# 1.1 安装 Node.js (v18+)
# https://nodejs.org

# 1.2 安装 Python (3.10+)
# https://python.org

# 1.3 安装 Git
# https://git-scm.com

# 1.4 安装 VSCode + 插件
# - ESLint
# - Prettier
# - Python
# - Thunder Client (API测试)
```

### 步骤2：仓库创建（1小时）

```bash
# 2.1 创建GitHub仓库
# 访问 https://github.com/new
# 仓库名：taskplatform

# 2.2 本地初始化
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/taskplatform.git
git push -u origin main
```

### 步骤3：数据库配置（3小时）

```bash
# 3.1 创建Supabase项目
# 访问 https://supabase.com/dashboard

# 3.2 获取连接信息
# Settings → API
# - Project URL
# - anon/public key
# - service_role key

# 3.3 在SQL Editor执行
# 复制 web/supabase_init.sql 内容并执行

# 3.4 验证连接
curl -X GET "你的URL/rest/v1/material_categories" \
  -H "apikey: 你的KEY"
```

### 步骤4：后端开发（3天）

```bash
cd web/backend

# 4.1 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 4.2 安装依赖
pip install -r requirements.txt

# 4.3 启动开发服务器
uvicorn main:app --reload --port 8000

# 4.4 测试API
curl http://localhost:8000/health
```

### 步骤5：前端开发（4天）

```bash
cd web/frontend

# 5.1 安装依赖
npm install

# 5.2 启动开发服务器
npm run dev

# 5.3 访问 http://localhost:3000

# 5.4 配置API地址
# 创建 .env 文件
VITE_API_URL=http://localhost:8000
```

### 步骤6：云端部署（2天）

```bash
# 6.1 部署前端到Vercel
cd web/frontend
npm run build
npx vercel

# 6.2 部署后端到Cloudflare Workers
cd web/backend
npx wrangler deploy

# 6.3 配置定时任务
# 在 wrangler.toml 中设置 crons
```
