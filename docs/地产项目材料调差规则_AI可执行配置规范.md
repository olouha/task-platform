# 地产项目材料调差规则 · AI 可执行配置规范（完整版）

> **版本**: v2.0  
> **用途**: 供任意 AI / 计算引擎自动理解、解析、计算材料调差，无需改代码、无歧义、可扩展、可审计  
> **适用材料**: 钢筋、商品混凝土、加气砌块、PC 构件钢筋、电缆、人工费、砌体、商品砂浆、ALC墙板、钢管  
> **覆盖项目**: 朱家庄旧村改造、青特地产、莱山区第二实验小学、豪森海天映月、龙湖集团

## 2. 调差公式模板（AI 必须支持 5 种）

### 2.1 标准三段式（最常用，有风险幅度）

```
情况1 - 超幅度上浮（施工均价 > 基准价 × (1 + 风险幅度)）：
  调整金额 = 工程量 × (施工均价 - 基准价 × (1 + 风险幅度)) × (1 + 税率)

情况2 - 超幅度下浮（施工均价 < 基准价 × (1 - 风险幅度)）：
  调整金额 = 工程量 × (施工均价 - 基准价 × (1 - 风险幅度)) × (1 + 税率)

情况3 - 幅度内（不调差）：
  调整金额 = 0
```

### 2.2 无风险幅度（全额调差，0%风险幅度）

```
调整金额 = 工程量 × (施工均价 - 基准价) × (1 + 税率)
```

### 2.3 比例调差法（豪森模式）

```
涨幅（Pi/P0 > 1 + 风险幅度）：
  调整金额 = P0 × (Pi/P0 - (1 + 风险幅度)) × Qi × (1 + 税率)

跌幅（Pi/P0 < 1 - 风险幅度）：
  调整金额 = P0 × (Pi/P0 - (1 - 风险幅度)) × Qi × (1 + 税率)

其中：
  P0 = 基准价，Pi = 施工均价，Qi = 工程量
```

### 2.4 造价信息调整法（朱家庄模式）

```
涨幅超风险幅度：
  调整金额 = 工程量 × (信息价 - 基准价 × (1 + 风险幅度)) × (1 + 税率)

跌幅超风险幅度：
  调整金额 = 工程量 × (信息价 - 基准价 × (1 - 风险幅度)) × (1 + 税率)

幅度内：
  调整金额 = 0
```

### 2.5 龙湖增值税率换算法（含税价与不含税价换算）

```
钢筋（无风险幅度，全额调差）：
  调整金额 = {工程量 × [指导价 - 基价]} / (1 + 增值税率) × (1 + 合同增值税率)

混凝土（有±3%风险幅度）：
  涨幅>3%：
    调整金额 = {工程量 × [指导价 - 基价 × 1.03]} / (1 + 增值税率) × (1 + 合同增值税率)
  跌幅>3%：
    调整金额 = {工程量 × [指导价 - 基价 × 0.97]} / (1 + 增值税率) × (1 + 合同增值税率)
  幅度内：
    调整金额 = 0

注意：
  - 指导价和基价为含税价，需先除以(1+增值税率)转为不含税
  - 承包人采购钢材增值税不计入调整金额
  - PC构件工程量按发包人确认的深化图纸计算
```

### 2.6 举例说明

> **配置**: 钢筋，风险幅度 ±3%，税率 9%  
> **基准价**: 4000 元/吨  
> **施工均价**: 4200 元/吨  
> **工程量**: 1000 吨

**判断**: 4200 > 4000 × 1.03 = 4120，属于超幅度上浮

**计算（标准三段式）**:
```
调整金额 = 1000 × (4200 - 4000 × 1.03) × 1.09
         = 1000 × (4200 - 4120) × 1.09
         = 1000 × 80 × 1.09
         = 87,200 元
```

**计算（龙湖增值税率换算法，假设增值税率13%）**:
```
调整金额 = {1000 × [4200 - 4000]} / (1 + 0.13) × (1 + 0.09)
         = 1000 × 200 / 1.13 × 1.09
         = 200000 / 1.13 × 1.09
         = 176991.15 × 1.09
         = 192,920.35 元
```

## 3. AI 执行标准流程（固定 6 步）

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 读取配置 → 校验必填项                        │
│    - 读取 24 项配置                                   │
│    - 校验必填项是否完整                                │
│    - 配置缺失 → 明确提示缺失字段并终止                  │
├─────────────────────────────────────────────────────┤
│  Step 2: 取基准价                                    │
│    - 根据基准价来源和取价规则确定基准价                  │
│    - 无价格 → 按配置规则顺延/取均价，不猜值             │
│    - 龙湖模式：含税基准价需标注增值税率                  │
├─────────────────────────────────────────────────────┤
│  Step 3: 取施工期均价                                 │
│    - 按施工期价格采集规则采集价格                        │
│    - 按节假日/无价处理规则处理缺失价格                   │
│    - 按短周期处理规则处理 ≤7天的情况                    │
│    - 龙湖钢筋：每月5/15/25号采样取均值                  │
│    - 龙湖混凝土：每月《青岛材价》算术平均值              │
├─────────────────────────────────────────────────────┤
│  Step 4: 判断是否超风险幅度                            │
│    - 对比施工均价与基准价 × (1 ± 风险幅度)              │
│    - 风险幅度=0% → 全额调差，无需判断超幅               │
│    - 幅度内 → 调整金额 = 0                            │
├─────────────────────────────────────────────────────┤
│  Step 5: 代入公式计算                                 │
│    - 根据调差公式模板计算调整金额                        │
│    - 龙湖模式：含税价/(1+增值税率)×(1+合同税率)         │
│    - 根据负数处理规则处理跌价情况                       │
│    - 根据取费规则确定最终金额                           │
├─────────────────────────────────────────────────────┤
│  Step 6: 输出结果                                    │
│    - 总调差金额 + 明细 + 计算依据                       │
│    - 标准 JSON 格式输出                               │
└─────────────────────────────────────────────────────┘
```

## 4. 异常处理规则（AI 必须遵守）

| 异常情况 | 处理方式 | 禁止行为 |
|---------|---------|---------|
| 无价格数据 | 按配置规则顺延/取均价 | ❌ 不猜值、不填0 |
| 工程量为 0 或负数 | 报错并提示具体行项 | ❌ 不跳过、不取绝对值 |
| 公式计算错误 | 定位错误位置并终止 | ❌ 不继续计算 |
| 配置缺失 | 明确提示缺失字段名称 | ❌ 不使用默认值 |
| 合同与配置冲突 | 提示冲突内容并等待确认 | ❌ 不自行决定 |
| 含税价与不含税价混合 | 按公式模板要求统一口径 | ❌ 不混合计算 |

## 9. 扩展规则

1. **新增项目**: 只需按 24 项填写配置，AI 即可自动适配、自动计算，无需修改本规范
2. **新增材料**: 在 `调差项目` 数组中添加新对象即可
3. **自定义公式**: 当 `调差公式模板` 为"自定义"时，需在配置中增加 `自定义公式` 字段
4. **版本管理**: 每次配置变更应更新 `使用规则版本` 字段
5. **含税/不含税混合**: 龙湖模式下，需明确标注价格是否含税，按公式模板自动换算
