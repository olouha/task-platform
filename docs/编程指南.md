# TaskPlatform 成员编程指南
## 如何使用 Claude Code 开发

---

## 一、Claude Code 基础操作

### 1.1 启动 Claude Code

```bash
# 在项目目录下启动
cd taskplatform
claude
```

### 1.2 Claude Code 常用命令

| 命令 | 作用 | 示例 |
|------|------|------|
| `/help` | 显示帮助 | 查看所有命令 |
| `/clear` | 清除对话 | 重新开始 |
| `/review` | 代码审查 | 检查代码质量 |
| `/test` | 运行测试 | 执行测试用例 |
| `/submit` | 提交代码 | 提交到 git |

### 1.3 常用提示词

```
"继续"          - 继续上次的任务
"解释一下这段代码" - 解释代码
"帮我写测试"    - 生成测试用例
"检查错误"      - 查找 bug
"优化性能"      - 性能优化建议
```

## 三、B（后端）编程指南

### 3.1 启动 Claude Code

```bash
cd taskplatform/web/backend
claude
```

### 3.2 常用指令示例

#### 指令1：创建 API

```
提示词：
"创建材料管理的 CRUD API：
POST /api/materials     - 创建材料
GET /api/materials      - 获取列表（支持分类筛选）
PUT /api/materials/:id   - 更新材料
DELETE /api/materials/:id - 删除材料

数据库表：materials（id, category_id, name, spec, unit, base_price）
保存到 api/materials.py"
```

#### 指令2：实现调差计算

```
提示词：
"实现调差计算逻辑：
1. 输入：项目ID、阶段ID、材料列表、基准价、现价
2. 计算：价差 = (现价 - 基准价) / 基准价 * 100%
3. 判断：超过阈值（默认5%）才计算调差
4. 输出：调差金额、调差率、是否触发

保存到 services/adjustment_calculator.py"
```

#### 指令3：实现价格抓取

```
提示词：
"实现我的钢铁网价格抓取：
1. 访问 https://www.mysteel.com.cn/price/rebar
2. 使用 CSS 选择器 .price-value 提取价格
3. 解析数字（去掉 ¥ 和 逗号）
4. 保存到 price_history 表

参考：services/price_scraper.py"
```

#### 指令4：测试 API

```
提示词：
"帮我写测试用例验证调差计算：
- 基准价 4200，现价 4500，数量 500吨
- 期望结果：调差率 7.14%，调差金额 150000元"
```

## 六、常见问题处理

### 6.1 遇到报错怎么办

```
用户: 前端报错了 'Module not found'
Claude: 这通常是依赖缺失或路径错误。

检查中...
  1. 检查 node_modules 是否存在
  2. 检查 import 路径是否正确
  3. 检查文件是否在正确位置

解决方案：
  npm install
  或检查 import 语句

需要我帮你检查吗？
```

### 6.2 代码不工作怎么办

```
用户: API 返回 500 错误
Claude: 这是服务端错误。

检查中...
  1. 查看后端日志
  2. 检查数据库连接
  3. 检查 API 逻辑

可能原因：
  - 数据库连接失败
  - 参数格式错误
  - 服务器异常

需要我帮你排查吗？
```

### 6.3 需要帮助时

